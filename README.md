# Future_DS_02 – SOCIAL MEDIA CAMPAIGN PERFORMANCE TRACKER

## Overview
This repository contains my **SOCIAL MEDIA CAMPAIGN PERFORMANCE TRACKER** completed as part of the **Future Interns Data Science Internship**.  
The dashboard analyzes marketing campaign performance across multiple channels, providing key metrics, visual insights, and actionable recommendations.

---

## Files
- `task2.pbix` → Power BI file containing all visuals and charts.  
- `Advertising_Data.csv` → Original dataset used for analysis.  
- `dashboard2.JPEG` → Key charts and KPI cards for reference.  
- `Insights/` → Summary of observations and recommendations.

---

## Dashboard Highlights
1. **KPI Cards**  
   - Total Revenue  
   - Total Spend  
   - ROI (137%)  

2. **Spend by Marketing Channel**  
   - Column chart showing budget allocation per channel.  

3. **ROI by Marketing Channel**  
   - Horizontal bar chart highlighting top and low-performing channels.  

4. **Revenue vs Spend by Channel**  
   - Clear view of efficiency gaps across channels.  

5. **Insights Section**  
   - Data-driven recommendations based on performance metrics.  
   - Key observation: *“Overall campaign performance is positive with an ROI of 137%”*
